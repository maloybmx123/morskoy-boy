# Морской бой — онлайн

Браузерная многопользовательская игра для Android, iPhone/iPad и Windows. Игроки подключаются по коду комнаты, настраивают поле и флот, расставляют корабли, затем стреляют по очереди.

## Что уже реализовано

- Комнаты с кодом, до 8 игроков.
- Размер поля от 6×6 до 20×20.
- Классический, небольшой и пользовательский флот.
- Автоматическая расстановка и ручная расстановка кораблей.
- Скрытые корабли противников; отметки попаданий и промахов.
- Очерёдность ходов, повторный выстрел при попадании (можно отключить).
- Счёт палуб, выбывание игрока и определение победителя.
- Адаптивный интерфейс для телефонов и компьютеров.

## Запуск на своём компьютере

Нужен Node.js 18 или новее.

1. Распакуйте архив.
2. Откройте терминал в папке проекта.
3. Выполните `npm install`
4. Выполните `npm start`
5. Откройте `http://localhost:8080`

Для игры нескольких людей на одном Wi-Fi откройте на других устройствах адрес компьютера в локальной сети, например `http://192.168.1.20:8080`. Адрес компьютера можно посмотреть в настройках сети. Разрешите входящие подключения для порта 8080 в брандмауэре, если Windows спросит.

## Игра через интернет

Чтобы друзья подключались из разных сетей, проект нужно разместить на хостинге, который поддерживает Node.js и WebSocket (например, VPS или платформа для Node-приложений). Укажите порт через переменную окружения `PORT`; платформа должна проксировать WebSocket и HTTPS. После размещения отправьте друзьям публичную HTTPS-ссылку.

## Важные ограничения первой версии

- Для сетевой игры нужен постоянно работающий сервер; один только HTML-файл не синхронизирует ходы между телефонами.
- Если игрок закроет вкладку, он отключится. Восстановление сессии после переподключения пока не реализовано.
- Для серьёзной публичной эксплуатации стоит добавить серверную проверку корректности и непересечения кораблей, защиту от подмены сообщений, повторное подключение и постоянное хранение комнат. Это стартовая рабочая версия, а не защищённый турнирный сервис.
